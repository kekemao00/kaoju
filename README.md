# kaoju（考据）

> 无征不信，孤证不立。
> *Nullius in verba.*

面向不可信上游的代理池网关。把公开免费代理列表和免费节点订阅（不可信）
与自有或付费代理（可信）汇成一个统一入口，提供轮换与会话粘性。

名字取自清代考据学的规矩：没有证据的不信，只有一条证据的不下结论。
项目对上游代理和对自己都照这个规矩办：上游说的每一句话都由独立的见证方核对，
本项目对外的每条声明都附第三方可以复现的证据。

状态：研究阶段。网关本身还没有代码；第一阶段的实测工具已经写好，等待在服务器上运行。

## 使用边界

本项目用于在获得授权的前提下做代理调度与管理的工程实践。
请遵守所在地法律、目标站点的服务条款，以及所用代理来源的许可。
不要用它做未授权访问、绕过访问控制、欺诈或滥用流量。
